## Build with Qwen3-TTS w/ Docker:
```
docker compose -f qwen3-compose.yaml build --no-cache
```

## Run w/ Docker Compose:
```
docker compose -f qwen3-compose.yaml up
```

## Stop Docker Compose:
```
docker compose -f qwen3-compose.yaml down
```
